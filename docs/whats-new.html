Changelog

What's new

Recent releases have been about trust: imports that refuse a crafted reply, text from your correspondents shown exactly as written and reading panes that behave, then read themselves. Before that came a website with a page for each part, a move you can look at and take back before you send it, a donate button and an update check disclosed in full. The first full release settled the email format, so a long game outlives any one version of the app.

v1.6.0

Help and licence text reads itself

  • The About page and the licence windows, in the app and in the installer, now scroll gently by themselves: a few seconds' pause on opening, a slow descent, a pause at the end, then back to the top
  • Touching the text with the wheel, the scrollbar, a click or the keys stops it where you left it; after a moment of stillness it carries on from there rather than jumping back to the top
  • Text that already fits stays still; a window open on top of another stops the one underneath until it closes
  • The email you are about to send and the box you paste a reply into never move by themselves
v1.5.1

Reading panes no longer light up

  • Tabbing into the About text, a licence or the preview of the email you are sending no longer draws a highlight round the whole page; once the text fits its box, Tab passes straight over it
  • The box you paste a reply into still lights up as you Tab to it, since that is where you type
  • The installer's licence windows open with Close ready; a click into the text no longer takes the keyboard away from the buttons
v1.5.0

Safer imports

  • A crafted reply can no longer end the game by writing a result into its tags, accept a draw nobody offered, pass instead of moving, start from a different position or play a move for your side; each is refused and your game is left as it was
  • A reply that catches up after a missed email is still accepted, as long as your own moves in it match the ones you played
  • A game identifier not in the form the app writes is refused, so a message can no longer reach a file outside your games folder or stand in for another game
  • A move typed by an opponent without the app above your quoted email is now picked up and routed to the right game; a pasted game record with no move block around it is refused with a clear reason rather than guessed at
  • Names, addresses and other words from an email are always shown exactly as written, never drawn as formatting
  • A damaged saved game no longer stops the app opening: the rest are listed, the damaged file is left untouched and you are told once the window appears
  • The documentation and the site now say plainly that a threefold repetition or fifty-move draw is reached by offering a draw, since there is no claim button
v1.4.0

A website with a page for each part

  • The site was one long page; it now has a short home page with Features, Why and Download each on a page of their own, reached from the same navigation everywhere
  • The stylesheet link carries a fingerprint of the stylesheet, so a browser never shows a new page with an old cached look
  • The update check now quietly drops its answer if the window has already gone, rather than raising an error on its background thread
  • Building from source on Windows and macOS needs Nuitka 4.2.1 or later; each build script checks before compiling and stops with both versions and the install command
  • DECISIONS-TRADEOFFS.md records the decisions Postal Gambit rests on with what each one gains and costs; the developer documents were read against the code and corrected where they had drifted
v1.3.1

A new donation page

  • The Donate button now opens a new PayPal page that suggests £5 and lets you give any amount you choose; nothing else has changed
v1.3.0

Playing a move and sending it are two separate acts

  • Playing a move no longer throws the email up over the board: the board updates and the move waits until you press Send move
  • Send move greys out once the email leaves for your mail client or clipboard, so each move goes out once; it replaces Re-send last email
  • A move you have played but not yet sent can be taken back with Take back move. Once the email is handed off it counts as gone, since your opponent may already be replying
  • A game with an unsent move reads "move not sent" rather than "waiting" in its row and on the status line
  • A draw offered with a move travels with the game, so it is still on the move whenever you send it
  • File letters and rank numbers run round all four edges of the board and turn with it when you play Black
v1.2.0

Focus rings on controls; a way to say thanks

  • The game list and the move history no longer draw a border round themselves when focused; the highlighted row shows where you are and keeps its place when the board refreshes
  • The About text, the licence text and the email preview now show a ring when focused and are reached by Tab only while they hold more than fits
  • A donate button sits on a strip of its own at the foot of the window; nothing is held back behind it, there is no paid tier and no licence key
  • The button hands the address to your browser, so Postal Gambit still opens no connection of its own
  • The site gained a matching section at the foot of the home page
v1.1.1

A setup program that stays to the end

  • Asking the setup program to close a running Postal Gambit before an upgrade could make the setup window vanish with nothing installed; it now ends the application alone
  • When the setup program cannot start Postal Gambit after installing, its window stays open, says the install itself succeeded and points at the program so you can start it yourself
v1.1.0

An update check that respects you, disclosed in full

  • Shortly after launch and once a day, the app asks GitHub anonymously whether a newer published release exists; Help > Check for updates asks on demand
  • When one is found you choose Download, Skip this version or Later; a skipped version never prompts again and a failed check stays silent
  • Your games and moves still never touch the network: your mail client remains the only transport and nothing about you or your games leaves your machine
  • The structural tests now forbid network code everywhere except that one named module and assert that the exemption cannot widen
  • On Linux the Flatpak gains network access for this one call; an existing install keeps its old permissions until reinstalled from a rebuilt bundle
v1.0.0

The email format is settled

  • The format of the block inside every Postal Gambit email is frozen, so two copies on different releases can keep playing one long game; anything that would break it takes a new version marker of its own
  • The no-network check now covers everything that reaches your machine, the setup program included; it also fails the build if anyone narrows it
  • The setup program closes when it has finished instead of sitting frozen after launching Postal Gambit
  • Postal Gambit and its setup program show their own names in Task Manager
  • The setup program offers to close a running Postal Gambit for you, shows each phase with its progress and keeps the sign-in tick box as you had it
  • Extraction checks every file in the bundle, so a malformed archive cannot place a file outside the install folder
  • The site presents Postal Gambit for Windows, macOS and Linux with a card for each platform and download buttons that follow the newest release; a new Why page sets out the reasoning behind it
  • For anyone reading the source: the part of the setup program that touches your machine is tested at 100% coverage and a standing technical-debt document records what is open
